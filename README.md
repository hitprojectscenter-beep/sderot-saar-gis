# מפת סע״ר שדרות

מערכת GIS ליחידת סע״ר (סיוע עצמי ראשוני) שדרות. מפה מבצעית שעובדת גם בלי רשת, לקליטה ולהנגשה של נתונים בשגרה ובזמן אירוע אמת: רעידת אדמה, פגיעת טיל ואירועי חירום אחרים.

## מה המערכת עושה

- **צפייה פתוחה לכולם, ללא כניסה.** הזנה ועדכון של נתונים – רק לבעלי התפקידים (ראו „משתמשים והרשאות”).
- **מפת העיר:** מפת רקע שנבנית מנתוני OpenStreetMap בסגנון המפה העירונית המודפסת: שטח עירוני אפור, פארקים בירוק, אזור תעשייה בסגול, שטחים למוסדות ציבור בחום; מבני מגורים בצהוב, ציבור בכחול, מסחר בוורוד ותעשייה בסגול; רחובות לבנים עם שמותיהם לאורכם, מספרי כבישים, מסילת הרכבת, שמות שכונות וסמלי מוסדות. כולל מקרא. המפה נשמרת במכשיר ועובדת גם בלי רשת.
- **שכבות GovMap:** כל השכבות הפתוחות של GovMap (WMS) זמינות בחירה ובחיפוש בחלונית השכבות.
- **הזנת נתונים** כנקודה, כקו או כשטח (פוליגון). לכל נתון יש שם, תיאור ותמונות.
- **רישום מעדכנים:** השרת שומר מי יצר כל נתון, מי עדכן אותו לאחרונה ואת היסטוריית העדכונים.
- **זיהוי שכבה אוטומטי** לפי השם והתיאור. לדוגמה, „ממ״ד”, „ברז כיבוי” או „בניין פגוע” משויכים לשכבה המתאימה. אפשר לשנות את השכבה ידנית.
- **34 שכבות ב-10 קבוצות:** מרחב העיר, מיגון, כיבוי אש, רפואה והצלה, מרכיבי ביטחון, תשתיות, אוכלוסיות ומוסדות, היחידה וקהילה בחירום, אירוע בזמן אמת וכללי.
- **עבודה בלי רשת:** כל שינוי נשמר במכשיר ונשלח אוטומטית כשהרשת חוזרת. אפשר לשמור במכשיר את מפת הרקע של שדרות.
- **התאמה לתנאי שטח:** כפתורים גדולים לעבודה עם כפפות, ערכות צבעים ליום, ללילה ולראיית לילה (אדום), הגדלת טקסט, הוספת נקודה במיקום ה-GPS בלחיצה אחת והכתבה קולית.
- **ייצוא** לאקסל (CSV) ול-GeoJSON, למשל להעברה לפקע״ר.
- **טעינת מפת העיר ושכבות הבסיס** בלחיצה אחת (תפריט ← „טעינת מפת העיר”): השרת מוריד מ-OpenStreetMap את המבנים, הרחובות ושימושי הקרקע, וגם ברזי כיבוי, דפיברילטורים, מקלטים, שכונות ומוסדות. את הטעינה הראשונה יכול לבצע כל בעל תפקיד; טעינה חוזרת – אחראי GIS. אחראי ה-GIS יכול גם להעלות קובץ GeoJSON כשכבת בסיס.

## משתמשים והרשאות

| תפקיד | role | הרשאות |
| --- | --- | --- |
| כל אחד, ללא כניסה | – | צפייה במפה, בנתונים ובתמונות, חיפוש וייצוא |
| אחראי GIS | `gis` | הזנה ועריכה, מחיקת כל נתון, עדכון שכבות בסיס |
| מפקד היחידה | `commander` | הזנה ועריכה, מחיקת כל נתון |
| סגן מפקד היחידה | `deputy` | הזנה ועריכה, מחיקת כל נתון |
| מפקדי צוותים 1–4 | `team` | הזנה ועריכה, מחיקת נתונים שהם יצרו |

הסיסמאות אינן נשמרות בקוד. הן נשמרות כגיבוב (scrypt) במשתנה הסביבה `USERS_JSON` ב-Vercel.

### החלפת סיסמאות

1. יוצרים קובץ `users.local.json`. הקובץ מוחרג מ-git, ואין להעלות אותו:
   ```json
   [
     { "username": "GIS_Admin", "password": "סיסמה-חדשה", "role": "gis" },
     { "username": "GROUP1_Admin", "password": "…", "role": "team", "team": 1 }
   ]
   ```
2. מריצים `node scripts/hash-users.mjs users.local.json`.
3. מדביקים את הפלט כערך של `USERS_JSON` בהגדרות הפרויקט ב-Vercel ומבצעים Redeploy.

## ארכיטקטורה

```
public/            אפליקציית הרשת (PWA): HTML, CSS ו-JS ללא שלב build
  js/layers.js     קטלוג השכבות והמסווג האוטומטי (משותף לשרת ולדפדפן)
  js/sync.js       סנכרון, תור שינויים במצב לא מקוון (IndexedDB)
  js/citymap.js    ציור „מפת העיר” בסגנון המפה המודפסת
  js/osm.js        המרת נתוני OpenStreetMap לשכבות הבסיס
  sw.js            Service Worker: קבצי האפליקציה, אריחי מפה ותמונות במצב לא מקוון
api/               פונקציות Vercel (Node.js)
  login, logout, me   התחברות (cookie חתום)
  features            קריאה וכתיבה של הנתונים (כתיבה אטומית עם ETag)
  photo               העלאה והצגה של תמונות
  base                שכבות בסיס
  city                מפת העיר: טעינה מ-OpenStreetMap (בשרת) והגשה
  govmap              רשימת השכבות הפתוחות של GovMap
```

האחסון הוא Vercel Blob פרטי. כל הנתונים נשמרים במסמך JSON אחד. כל כתיבה מתבצעת כ-compare-and-swap (`ifMatch`), כך ששני משתמשים ששומרים באותו רגע לא דורסים זה את זה. בפיתוח מקומי, כשאין טוקן, הנתונים נשמרים בתיקייה `.data/`.

## הקמה ב-Vercel (פעם אחת)

1. **Settings → Environment Variables:** מוסיפים `USERS_JSON` ו-`AUTH_SECRET` (הערכים נוצרים כמתואר למעלה) לסביבת Production.
2. **Storage → Create → Blob:** יוצרים Blob Store מסוג **Private** ומחברים אותו לפרויקט. `BLOB_READ_WRITE_TOKEN` נוסף אוטומטית.
3. **Deployments → Redeploy.**
4. נכנסים כבעל תפקיד ולוחצים בתפריט „טעינת מפת העיר”.

## משתני סביבה

| משתנה | תיאור |
| --- | --- |
| `USERS_JSON` | המשתמשים המגובבים (ראו למעלה) |
| `AUTH_SECRET` | מחרוזת אקראית של 32 תווים לפחות, לחתימת ה-session |
| `BLOB_READ_WRITE_TOKEN` | נוסף אוטומטית כשמחברים Blob Store לפרויקט |

## פיתוח מקומי

```bash
npm install
npm run vendor      # מעתיק את Leaflet ואת Geoman ל-public/vendor
npm test            # בדיקות המסווג האוטומטי
AUTH_SECRET=$(openssl rand -hex 32) USERS_JSON="$(node scripts/hash-users.mjs users.local.json)" npm run dev
# http://localhost:3000
```

## המשך פיתוח (לפי מסמך האפיון)

- לוח חפ״ק, מודיעין אוכלוסייה עם ייצוא בפורמט של פקע״ר, וקליטת מתנדבים (מודולים 5–7).
- מצב תרגול ותחקיר אוטומטי (מודול 8).
